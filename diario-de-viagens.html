Funcionalidades Principais

Geolocalização GPS

Capture coordenadas exatas de cada local visitado usando a API de Geolocalização do navegador.

Fotos e Mídia

Adicione links de imagens e exiba-as com elementos semânticos HTML5 como figure e figcaption.

Armazenamento Local

Suas memórias são salvas no localStorage, persistindo mesmo após fechar o navegador.

Avaliações Interativas

Use sliders (range) para avaliar de 1 a 5 estrelas suas experiências de viagem.

Gerenciamento de Entradas

Adicione, visualize e exclua entradas dinamicamente com manipulação do DOM.

HTML5 Semântico

Construído com tags semânticas como header, main, aside, section e article para acessibilidade.
